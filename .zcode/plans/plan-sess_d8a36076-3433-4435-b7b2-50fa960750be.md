## 目标
在管理后台新增"分区管理"功能：管理浏览内容页 4 张顶级卡片（技术资料/个人随笔/游戏记录/其他）下的**二级分类**（如技术资料下的 LangChain、Spring），支持增删/排序/重命名。二级分类数据由站点读取，新增分类即使无文章也显示在卡片上。

## 数据模型
新建 `src/data/sections.ts`，导出 `contentSections`（与现有 CONTENT_SECTIONS 结构对齐，每个分区增加 `categories: string[]`）：
```ts
export const contentSections = [
  { slug: "technical", title: "技术资料", description: "...", icon: "...", categories: ["LangChain","Spring","JavaSE",...] },
  { slug: "notes", ... }, { slug: "games", ... }, { slug: "other", ... },
];
```

## 站点侧改动（主仓库）
1. `src/utils/content-sections.ts`：改为从 `src/data/sections.ts` 读取分区与分类定义；`TECHNICAL_CATEGORIES/NOTES_CATEGORIES/GAMES_CATEGORIES` 三个 Set 由配置推导；`getContentSection` 映射逻辑保留。
2. `src/components/TechnicalCategoryCards.astro`、`src/components/NotesCategoryCards.astro`：分类列表 = 配置分类 + 文章实际分类 合并，按配置顺序排列（空分类也显示，计数 0 篇）。
3. `src/pages/category/technical/[category]/[...page].astro` 与 notes 对应页：`getStaticPaths` 的分类集合改为"配置分类 + 文章分类"合并，保证配置但暂无文章的分类也有详情页。

## admin 侧改动（独立仓库 BlogAdmin）
4. `admin/services/collections.mjs`：`dataCollections` 注册 `sections → src/data/sections.ts`（复用现有 findLiteralRange/writeCollection 管线）。
5. `admin/routes/index.mjs`：无需新增端点，复用 `GET/PUT /api/data/sections`（自动触发部署）。
6. `admin/public/index.html`：
   - 侧边栏新增"分区管理"导航按钮
   - 新增 `<section id="sections">` 视图：4 个分区 tab + 分类列表（增删、上下移动排序、重命名）
   - `show()` 函数标题映射追加分支
   - 分类编辑表单提交走 `PUT /api/data/sections`
7. （顺手）文章编辑器分类下拉 `postCategoriesBySection` 改为读 sections 配置，与站点一致。

## 兼容性
- `src/content/config.ts` 的 contentSection enum、文章 frontmatter category 均不变
- 文章实际出现但未配置的分类，仍自动出现在卡片里（兜底）
- 现有 162 篇文章分类归属不受影响

## 验证
- `pnpm build` 通过，检查 `/category/technical/` 卡片列表含新增配置分类（0 篇也显示）
- admin 启动后：分区管理视图可增删/排序/改名分类，保存后 `src/data/sections.ts` 正确更新
- 新增分类后其详情页 `/category/technical/<新分类>/` 可访问（0 篇空列表）
- 分别提交主仓库与 admin 仓库
