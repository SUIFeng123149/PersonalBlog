# 接口(interface)

1. 作用
传输数据
制定标准规范
降耦合
2. 接口语法
定义接口：
public interface 接口名{
[常量]
[抽象方法]
[默认方法和静态方法]
}

```java
 public interface IFirst {
    public static final String name = "TOM";
    //默认有abstract关键字
    public void firstMethod();
    //默认方法
    default public void firstMethod2(){
        System.out.println("firstMethod2");
    }
    //静态方法
    static public void firstMethod3(){
    }
 }
```

实现接口：关键字是implements ，其实实现接口 就相当于继承，只不过类和类是继承，类和接口是实现（特殊的继承）。类要重写接口中的所有抽象方法

**接口不能实例化**，创建接口实现类的对象

**一个类可以实现多个接口**

```java
 public class FirstImpl extends Object implements IFirst,ISecond {
    @Override
    public void firstMethod() {
        System.out.println("实现firstMethod方法");
    }
    @Override
    public void secondMethod() {
        System.out.println("实现secondMethod方法");
    }
 }
```

```java
public class FirstImpl extends Object implements IFirst,ISecond {
    @Override
    public void firstMethod() {
        System.out.println("实现firstMethod方法");
    }
    @Override
    public void secondMethod() {
        System.out.println("实现secondMethod方法");
    }
    public static void main(String[] args) {
        IFirst first = new FirstImpl();
        ISecond second = new FirstImpl();
        first.firstMethod();
    }
}
```

**接口和接口也可以继承(extends) ,是多继承**

```java
 public interface ITest extends IFirst,ISecond {
 }
```

## 工厂设计模式

将创建对象的过程封装到工厂类中，当我们要获取对象时，从工厂类中获取

```java
 public class VideoFactory {
    public static IVideo getVideoObject(){
        return new AQYVideo();
    }
 }
```

```java
 public class Test {
    public static void main(String[] args) {
        //出现了耦合度
        //Test类是我们的平台 ，TenVideo是腾讯公司的类
```

## 类图

1. 泛化/继承关系 ： 在编程时，子类 extends 父类
2. 实现关系： 在编程时，类 implements 接口
3. 依赖关系：在编程时，使用接口解决依赖关系，因为依赖关系不是稳定的，是可替换的，通常在方法的参数上使用接口类型，例如，司机要使用汽车，是依赖关系，在司机类的驾驶方法中的参数就是 交通工具接口。
4. 关联关系：在编程时，通过属性关联，例如在球员类中定义了一个球队属性 ，就是一个一对一的关联关系 ，例如在球队类中定义了一个球员的数组，就是一个一对多的关联关系。上面的两个例子组合，我们可以说球员和球队是双向关联。
