# Http协议

HTTP是一个客户端终端和服务器端请求和应答的标准（TCP），Http协议是基于TCP协议的。

HTTP协议的工作过程

## http协议的特点

  1. 无状态 ： http协议本身不保存任何数据的，数据可以由服务器或客户端进行一些存储
  2. 无连接：http请求响应结束后，就会释放连接，下次请求会建立新的链接 。提高并发的性能

### http请求报文

HTTP请求报文由请求行、请求头(报文头)、空行、请求体(报文体)组成

#### 请求方式
  1. GET请求 ： 通常要访问服务器资源时，使用GET请求。浏览器地址栏的请求、超链接的请求、表单默认的请求。GET请求的请求参数一定连接在URL地址的后面，意味着请求参数一定会在请求头中。造成请求的数据用户可以看到（不安全），地址是要显示在浏览器的地址栏中，地址栏是有长度限制的，如果发送大量的请求数据，数据 就会缺失了。
  2. POST请求 ： 通常客户端要向服务器发送较多数据时，使用POST请求。表单的method属性为post时，就是POST请求，通常都是在编程时指定的POST请求。请求参数会在请求体中。
  3. HEAD请求 ：通常获取服务器资源属性时，使用HEAD请求，HEAD请求的响应只有响应头没有响应体数据
  4. PUT请求： 要替换、修改服务器的资源（数据）时，使用PUT请求，在后面的REST风格中会使用
  5. DELETE请求 ： 要删除服务的资源（数据）时，使用DELETE请求

### 请求报文头

Accept:浏览器能够处理的内容类型

Accept-Language：浏览器当前设置的语言

Content-Type：请求报文体数据的数据类型，常用的数据格式：

默认的（**application/www-form-xx**） 名字=值&名字=值

上传文件格式（**multipart/form-data**） 二进制数据

xml格式(**application/xml**)

json格式(**application/json**) 组织结构化的数据，且轻量 ： {username:'tom',pwd:'123',name:'tom'}

{name:'tom',tel:['13312343121','1331111111']} {name:'财务部',id=5001,emps:[{name:'tom',age:20},{name:'jack',age:23}]} 

Cookie : 客户端存储的用户状态 提交给服务器

## http响应报文

HTTP响应报文由响应行（状态行）、响应头(报文头)、空行、响应体(报文体)组成

## 响应状态码

200 ： 响应成功

4XX ： 客户端的错误

400 ： Bad Request : 通常都是请求数据的格式错误，服务器无法解析

401 ： Unauthorized : 在访问资源前，没有进行身份认证，身份认证失败

403 ：Forbidden : 服务器能识别客户端请求，但是现在无法处理请求

404 ：Not Found : 客户端访问资源的地址不正确

405 : Method Not Allowed ： 服务器没有提供处理该请求方法的程序

5XX ： 服务器端的错误

500 ： Internal server Error ： 服务器内部错误，服务器上的代码抛出异常

502 ：Bad GateWay ： 网关接收到了一个 无效的请求 。

# Https协议

Https协议 = http协议 + SSL协议 ，http协议负责数据的传输（请求响应），SSL协议负责数据的安全

安全性上SSL体现了两点：

1. 为数据进行加密
2. 保证网站或系统的真实性 ： SSL数字证书

Http和Https的区别：

1. http端口号是80 ； https端口号是 443
2. http传输的都是明文；https传输的数据是加密的数据
3. https = http + SSL
