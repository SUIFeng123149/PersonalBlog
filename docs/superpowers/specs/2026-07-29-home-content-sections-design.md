# 首页内容分区设计

## 目标

降低首页文章列表的认知负担：在首页提供四个一级内容入口，并让读者进入入口后继续使用现有的文章卡片、分页、侧边栏和整体视觉风格，只展示该分区的文章。

## 一级分区

首页展示以下四个入口：

| 分区 | 用途 | 收录规则 |
| --- | --- | --- |
| 技术资料 | 教程、开发与技术沉淀 | 显式映射的技术类 `category` |
| 个人随笔 | 日常、思考与个人记录 | 显式映射的随笔类 `category` |
| 游戏记录 | 游戏体验、攻略与进度 | 显式映射的游戏类 `category` |
| 其他 | 不属于前三项的内容 | 自动兜底，避免文章消失 |

当前仓库内绝大多数文章为技术分类。因此初始映射会将已有的 Java、Web、MySQL、BigData、LLM、AI Agent、Dify、LangChain、LangGraph、DeepSeek、RAG、MCP、OpenAI、Prompt Engineering、Fine-tuning、Interview 等纳入“技术资料”。个人随笔和游戏记录的具体类别将以集中配置中的空映射开始，新增相应 `category` 后即可加入，无需改路由或组件。

## 页面与交互

1. 首页 Banner 下渲染四张响应式分区卡片；卡片包含图标、标题、说明、文章数量与进入箭头。
2. 每张卡片链接到稳定的英文 slug 路由：`/category/technical/`、`/category/notes/`、`/category/games/`、`/category/other/`。
3. 首页在分区卡片后仅展示 6 篇精选文章：置顶文章优先，再按现有发布时间顺序补足；首页不显示分页或全量文章入口。
4. 分区页面使用与首页相同的 `MainGridLayout`、`PostPage`、卡片样式与分页，仅数据源被一级分区过滤；页面顶部显示当前分区标题、说明和返回首页的链接。
5. 空分区保留可访问的页面，明确说明当前暂无文章并提供返回首页的入口，避免死链。
6. 原有细分类目录、标签、归档和文章 URL 保持不变；全量文章仅通过四个内容分区访问。

## 实现边界

- 新建一个内容分区配置/工具模块，作为一级分区元数据及文章归类的唯一来源。
- 新建可复用的分区入口组件和分区路由；不复制文章卡片或分页实现。
- 首页路由只向 `PostPage` 传入前 6 篇已排序文章，并移除其分页组件。
- 分区入口沿用站点现有 CSS 变量、圆角、明暗主题与移动端断点；键盘聚焦和链接文本保持可访问。
- 不修改现有文章 frontmatter；“其他”分区由未匹配分类自动计算。

## 验证

- 为分区归类工具建立测试：技术分类正确归入技术资料、已知随笔/游戏类别可映射、未映射和空分类进入其他。
- 为首页精选工具建立测试：置顶文章优先，且结果最多包含 6 篇。
- 构建/类型检查确认所有静态路由均生成且 Astro 页面无错误。
- 目测检查首页与任一分区页在桌面和移动宽度下的布局，确认链接、数量与筛选结果一致。
